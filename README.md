Stablecoin Depeg Prediction System
A modular C++17 event-processing backend with a lock-free SPSC queue, live and replayable data sources, explainable alerts, circuit-breaker handling, and SQLite persistence paths.

The repository reports 8.37M in-memory queue events/sec and 10.9 μs p99 local decision latency in separate benchmarks. Network latency is excluded; these figures describe local benchmark paths, not end-to-end production performance.
